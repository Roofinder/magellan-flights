# Keyword research — Magellan Flights

Built following the SEO video's Keyword Magic method, with the same three filters:

1. **Volume** — only keywords with ~100+ US searches/month.
2. **Keyword Difficulty (KD)** — target **≤ 30** (achievable for a brand-new domain).
   A few higher-KD "head" terms are kept as *stretch* primaries for clusters.
3. **Intent** — Informational keywords → **blog posts**; Transactional/Commercial
   → **money/service pages** (which we already have: market, world, explore,
   last-minute, airports).

## ⚠️ About the numbers
Your current Semrush plan does **not** include API/MCP access, so these volume +
KD figures are **expert estimates** calibrated to the travel/flight-deals niche,
not live Semrush pulls. The *method, structure, and clusters are identical* to
the video. To swap in live data later: get Semrush API access (or export a CSV
from the Keyword Magic Tool) and replace the Volume/KD columns — nothing else
changes.

## Files
- `blog_keywords.csv` — informational keywords → blog posts (low KD, build authority)
- `money_keywords.csv` — commercial/transactional → existing service pages
- `keyword_clusters.md` — 6 ready-to-write blog clusters (1 primary + 4 secondary)

## Strategy (why blogs first)
A brand-new domain can't rank for high-KD money terms like "cheap flights"
(KD 60-90) yet. The video's move — and ours — is to publish a cluster of
**low-KD informational blog posts** first. Those rank quickly, raise the domain's
authority, and *pull the money pages up* with them. Each blog post also links to
the relevant money page (internal linking), passing that authority where it earns.
